How to run the project

Take a New Terminal 


Run this to activate virtual environment        `` venv\Scripts\activate ``

Run this to run project         ``  python manage.py runserver  ``

how to open database in Sqlite

Open Sqlite > Click on File > C:\Final Year Project\Plant Disease Detection
